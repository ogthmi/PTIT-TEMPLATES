# PTIT PowerPoint Templates

Kho template PowerPoint phục vụ báo cáo kỹ thuật, đồ án, bài thuyết trình mang phong cách PTIT kỹ thuật, tối giản, dễ chỉnh sửa.

Lưu ý: template có thể không phù hợp với khối ngành kinh tế vì thiết kế đơn giản.

---

## Danh sách template
