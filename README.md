# PTIT PowerPoint Templates

Kho template PowerPoint phục vụ báo cáo kỹ thuật, đồ án, bài thuyết trình... mang phong cách PTIT kỹ thuật — hiện đại, tối giản, dễ chỉnh sửa.
<br><br>
> Lưu ý: template có thể không phù hợp với khối ngành kinh tế vì quá đơn giản.


## Danh sách template

Repo hiện có 3 template:

## Hướng dẫn sử dụng (dành cho Microsoft PowerPoint - Office 365)

1. **Tải template** `.potx` bạn muốn sử dụng từ repo này.

2. **Lưu file vào thư mục template của Office**:
   - Mở **File Explorer** (Windows).
   - Tìm thư mục `Documents` (thường là `C:\Users\<Tên người dùng>\Documents`).
   - Tìm thư mục con có tên **Custom Office Templates**.
   - Dán file `.potx` vào thư mục đó.

3. **Tạo bản trình bày mới từ template**:
   - Mở PowerPoint.
   - Chọn **New** (Tạo mới).
   - Ở thanh lựa chọn phía trên, chọn thẻ **Custom** (Tuỳ chỉnh).
   - Mở thư mục **Custom Office Templates**.
   - Chọn template bạn vừa thêm.

4. **Bắt đầu chỉnh sửa slide theo nội dung báo cáo của bạn.**
