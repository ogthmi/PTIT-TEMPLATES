## Hướng dẫn sử dụng

### Cách 1: Sử dụng trực tiếp
1. Tải file [PTIT] Final Project Template - Light Red 43.potx.
2. Mở trực tiếp file để PowerPoint tạo bản trình bày mới dựa trên template.
3. Chỉnh sửa nội dung, số liệu và hình ảnh theo yêu cầu đề tài.

### Cách 2: Cài đặt vào Custom Office Templates
1. Sao chép file potx vào thư mục:
   C:\Users\Username\Documents\Custom Office Templates
2. Mở PowerPoint, chọn New, chọn thẻ Custom, mở thư mục Custom Office Templates và chọn template để khởi tạo.
